# 漫画分镜 3D

[**中文**](README.md) ｜ [日本語](README.ja.md)

**中日双语（中文 / 日本語）的漫画分镜排版工具** — 在浏览器里用 3D 摆好舞台与人物，用相机按画幅取景，保存成一格格「画面」；再用「漫画分格（ネーム）」把画面拖进亲手拉线分好的分格里，接着用「对话气泡（ふきだし）」加上台词、心声与旁白，最后按页导出整本漫画的 PNG。

- 纯前端（Three.js r169，已随包，离线可用）＋ 零依赖本地静态服务器
- 不做任何上传，工程与自动保存都在你自己的浏览器里

---

## 启动

| 系统 | 做法 |
| --- | --- |
| macOS | 双击 **`start.command`**（首次可能需要在「系统设置 → 隐私与安全性」里允许） |
| Windows | 双击 **`start.bat`** |
| 命令行 | `node server.mjs 8765` 或 `bash start.sh` |

浏览器会自动打开 <http://127.0.0.1:8765/index.html>。关闭该终端窗口即停止服务。

首次打开（本机还没有自动保存的工程时）会直接进入**希腊神庙（外景）＋ 线稿＋明暗**的示例状态：神殿正面的机位、5m 网格，广场上站着两个人偶当比例尺。
之后每次打开都会恢复你上次的进度（自动保存）；想回到这个默认状态可以清掉浏览器数据，或用工具栏的「新建」开一个空工程。
需要 **Node.js 18+**（只用来提供静态文件，不需要联网、不需要安装依赖）。

## 主要功能

### 1. 舞台预设
- **室外**：住宅街道、商店街、十字路口、森林、河滩、校园操场、车站站台、希腊神庙（外景）、江西古建筑民居（外景）、**旧岩崎邸（外景）**、**庐山民居（外景・瀑布）**
- **室内**：豪宅大厅、家庭 LDK、六叠单间、教室、办公室、咖啡馆、希腊神庙（内殿）、江西古建筑民居（内景）、**旧岩崎邸 洋馆（内景）**、**旧岩崎邸 和馆（内景）**
- **仅人物**：只有地面＋网格

> 希腊神庙按帕特农神庙实测比例搭建：长 69.5m × 宽 30.9m、三层台基、8×17 根多立克柱（柱高 10.3m、柱底 ⌀1.9m、柱距 4.29m），外景有额枋/三陇板/山花，内殿 19.2×30m 带双层 Π 形柱廊、11m 雅典娜像与反射水池；素材库新增「多立克柱」构件可单独使用。

> **旧岩崎邸**（东京・汤岛，1896 年竣工，Josiah Conder 设计）三栋建筑都做了：外景为木造两层**洋馆**（雅各布样式：紧坡屋顶、破风山墙、砖砌烟囱、老虎窗、朝庭园的两层外廊与成对推拉窗）+ 单层**和馆**（瓦顶深檐、格子障子、广缘）+ **撞球室**与连接廊，配草坪、碎石路、池、雪见石灯笼、松樱与砖墙门柱；洋馆内景是两层通高的**玄関ホール + 大階段**（木制扶手与格子手摺子）、**大広間**（金唐革纸壁纸 + 暖炉 + 格天井 + 枝形吊灯）、**食堂**（长桌 + 8 椅）与寄木细工走廊；和馆内景是书院造**大広間**（榻榻米、床の間 + 違い棚 + 欄間、格子障子、面向池庭的广缘）。

> **江西古建筑民居**参考赣派（徽派影响）民居形制：外景是一条青砖灰瓦的村巷——三级马头墙、砖雕门罩配石库门、木格窗与山墙漏窗、青石板巷道、老樟树与巷尾水塘；内景是三开间厅堂的「**四水归堂**」天井——木柱石础、冬瓜梁、太师壁前的条案·八仙桌·太师椅、匾额楹联、隔扇门窗、二层跑马廊，天井下方还有石阶、排水明沟与石缸。

> **庐山民居（外景・瀑布）**：赣派民居坐在崖下石砌台地上，背后三级崖壁垂下一道 45m 的**直瀑**（瀑口岩唇 → 11 条纵向水帘 → 瀑底水台，落进带泡沫环与水花的岩潭），溪流自水潭绕过石阶流向画面前景；崖顶 45m 与坡上的松树、崖后三片远山剪影一起撑出景深。瀑布两侧的崖壁上各有一处**悬挑岩台**（左高 22.6m、右低 12.8m，苔顶台面约 10×9m），台面平整，可以直接把人偶拖上去站（拖放会落在鼠标下的朝上表面：崖台、家具、台地都一样）。

切换舞台时，**你自己摆放的家具和人物会保留**（舞台层与物件层分开管理）。
「我的舞台」可以把当前房间存到浏览器里，下次一键复用（例如主角的房间）。

### 2. 网格吸附
- 网格 10cm / 50cm / 1m / 5m，可关闭；户外舞台自动用 1m，室内自动用 10cm
- **拖动时按住 Shift** 可临时取消吸附
- 角度吸附 90° / 45° / 15°，可关闭
- **高度吸附**：把杯子、书本拖到桌面上会自动贴到桌面高度
- **贴墙吸附**：靠近墙面时自动贴齐
- 物体不会掉到地板以下

### 3. 相机（漫画专用）
- 焦距 24mm / 35mm / 50mm / 85mm 一键切换，也能用滑杆 18–120mm
- 目线预设：站立 150cm、坐姿 110cm、仰角（アオリ）、俯视（俯瞰）
- 倾斜（斜角镜头 / ダッチアングル）−30°～+30°
- 画幅：16:9 / 9:16 / 4:3 / 3:4 / 1:1 / 3:2 / 2:3 / 漫画页
- **每格画面可以单独保存相机**，命名切换（画面 1、画面 2…），一页多格的取景互不干扰

### 4. 人物
- 人偶共三种：**男性 / 女性 / 儿童**（方块构成的简易人偶）
- **身高按 cm 指定**（例：儿童 115cm、主角 172cm）
- 姿势预设：站立 / 坐 / 行走 / 指 / 躺
- 头部有鼻子朝向标记 + 头顶名称标签（A、B…可改名）
- 家具和人物比例永远正确（全部按真实厘米计算）

### 5. 外观与导出
- 外观：**线稿（柔和）**、线稿（浓）、明暗上色、线稿＋明暗
  - 线稿模式会给圆柱 / 圆锥 / 球体自动补上**随视角更新的侧影线**：神庙的柱子、树冠、石缸这些圆润形体在线稿下也有清晰的轮廓边，不再是白面糊成一片
- **线条抗闪烁**：3D 视口在显示分辨率之上做 1.5× 内部超采样（SSAA，像素总量超预算时自动退回 1:1），并让轮廓线不写深度——转动 / 平移相机时细线的亚像素抖动明显变平滑
- 辅助线：三分法构图线、透视线 / 消失点、视平线（地平线）、画面外变暗
- **只显示人偶**：一键去掉场景里所有背景物件（家具、建筑、道具…），只留人偶看姿势 / 走位
- **去掉墙壁遮挡**：一键把内景的墙 / 吊顶屋面隐藏成「剖面」视角，从室外或高处也能看清屋内（导出 PNG 时仍按完整场景渲染）
- 导出 PNG：宽度 1024–3840px，画幅比例与画面一致
  - **背景透明**（只留物件与人物的透明底图）
  - **分层导出**：同时输出「背景」和「人物」两张透明 PNG，拖进 Clip Studio / Photoshop 直接分层使用

### 6. 漫画分格（ネーム）
左侧抽屉菜单的第二个按钮就能切到这个功能（`3D 分镜` ⇄ `漫画分格`）。

- **多页面管理**：＋ 新页面 / 复制页面 / 删除页面 / 上下排序 / 改名，页面尺寸可选 B5 漫画页、正方形、横长、长条（Webtoon）
- **拉线分格**：用鼠标或触摸板在页面上拖一条线，线经过的分格会被自动切开（斜线、折角分格都行）；水平 / 垂直方向会自动吸附，按住 `Shift` 取消吸附
- **擦除分格线**：点一下分格线就能删掉它，相邻分格自动合并回一格（`⌘/Ctrl+Z` 可撤销）
- **页面设置**：内枠余白、分格间隙、线条粗细都能实时调整
- **把 3D 保存的画面放进分格**（三种方式，都会自动处理裁切）
  - 在「画面（分镜格）」列表里**拖动画面卡片** → 放进缩略页或分格编辑器里的任意分格
  - 先在左侧画面列表**点选画面**，再**点一下分格**
  - **自动填入本页 / 全部页**：按阅读顺序把没放置过的画面依次填进空分格
- **分格内构图调整**：选中分格后，在分格内拖动可移动画面，`⌘/Ctrl + 滚轮` 或右侧滑杆缩放，双击分格重置
- **格外遮罩**：选中的分格会把「超出这一格的部分」用**灰色 / 半透明**方式显示出来（也可选隐藏），一眼看清这一格最终会露出什么
- **分格序号**：按漫画阅读顺序（从右到左、从上到下）自动编号，画面卡片上也会显示「已放入 第1页·第2格」
- **导出**：当前页或全部页面导出 PNG（如 `name_p01_1600x2262.png`），按页序形成一整本漫画ネーム

### 7. 对话气泡（ふきだし）
左侧抽屉菜单的第三个按钮（`漫画分格` ⇄ `对话气泡`）。**和「漫画分格」共用同一套页面**——先把页面分好格、放进画面，再切到这里加台词。

- **五种气泡 + 纯文字**：点一下就能加到当前页面中央
  - **圆形・椭圆形**：最常用的普通对话 / 招呼
  - **云朵（丸の連なり）**：不出声的心声、内心嘀咕
  - **锯齿（ギザギザ）**：喊叫、愤怒、惊讶等强烈情绪
  - **点线（点線風）**：小声、悄悄话
  - **方形框（四角い枠）**：旁白、场景说明
  - **只有文字**：不要气泡，直接写文字（旁白 / 拟声词）
- **文字默认「竖排・从右到左・居中」**：自动按气泡形状折列并缩放，塞不进时会自己缩小；也可以一键改成横排。竖排时**每列至少 4 个字**，自动缩放会让每列尽量多排（比早期版本每列多约 2 字），不会出现一列只有一两个字的情况
- **编辑**：拖动气泡移动，右下角手柄缩放，圆形手柄拉出尾巴（引出线），倾斜滑杆可转角度；双击气泡直接输入文字；`字号` 滑杆可整体缩放文字；「贴合文字」把气泡收到刚好包住文字
- **统一编辑**：「统一编辑所有页面文字」一次改完所有页面上的文字，还能**全部改竖排 / 横排**、**统一字号**；取消可整体还原，确定后一次 `⌘/Ctrl+Z` 就能撤销
- **导出**：当前页或全部页面导出 PNG（分格画面 + 气泡 + 文字合成一张，`fukidashi_p01_1600x2262.png`），直接打印或贴进 Clip Studio

## 推荐流程

1. 顶部选一个**舞台**预设（决定室内 / 室外与网格精度）
2. 从左侧把家具、基本形状、人物拖进画面（点一下按钮也能添加）
3. 调相机：焦距、目线预设、画幅比例、倾斜
4. 点**保存为画面**记录这一格 → 移动相机 → 再保存下一格
5. 在**导出 PNG**里选尺寸，导出底稿（可透明底、可分层）
6. 切到左侧抽屉的**漫画分格**：＋ 新页面 → 用「拉线分格」把页面分成几格
7. 把「画面（分镜格）」里的画面拖进分格（或点「自动填入」），选中分格微调构图
8. 需要多页就继续 ＋，最后「导出全部页面 PNG」，一整本ネーム就完成了
9. 切到左侧抽屉的**对话气泡**：点左侧气泡类型加到页面上 → 双击输入台词（默认竖排从右到左）→ 拖动手柄调整大小 / 尾巴
10. 「统一编辑所有页面文字」可以一次改完所有页面的台词 → 「导出全部页面 PNG」，台词与气泡就合成进每一页了

## 经验（来自实测）

- 比「位置」更重要的是「**镜头**」。同一个房间，24mm 显得宽敞夸张，50mm 更自然——能一键切换正是 3D 的强项。
- **目线高度**决定画面是否自然：坐姿眼睛约 110cm、站立约 150cm。把相机对到人物眼睛高度，构图立刻像漫画。
- 外观选「**线稿（柔和）**」+ 白底，就能直接当描线底稿贴到 Clip Studio 的草稿层。
- 尺寸全部按真实厘米处理，家具与人物比例始终正确；高度吸附可以把东西直接放到桌面上。
- **切换舞台时你摆放的物件会保留**，所以可以先搭家具再换背景。

## 数据与隐私

所有计算都在本机浏览器里完成，不上传任何数据。
工程用「保存文件」导出成 JSON（3D 场景 + 分格页面都在同一个文件里），「打开文件」继续；「我的舞台」和自动保存存在浏览器 localStorage 里。
