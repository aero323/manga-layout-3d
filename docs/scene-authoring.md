# 场景模块编写指南（src/scenes/*.js）

> 这份文档是给「场景任务」用的：每个场景一个文件，互不冲突。**只改自己负责的那个文件。**

## 1. 模块契约

```js
import { kit } from '../stages.js';       // 唯一允许的 import

export const xxxStage = {
  id: 'xxx',                 // 已注册，不能改
  group: 'outdoor',          // 'outdoor' | 'room'（已定，不能改）
  grid: 1,                   // 吸附网格 0.1 / 1 / 5
  view: { pos: [x, y, z], target: [x, y, z], lens: 30 },  // 默认机位（可调）
  build: () => {
    const { box, cyl, col, wallRun, C, rng } = kit;   // 按需解构
    const out = [];
    // ... push 各种构件
    return out;
  },
};
```

- **一定要在 `build()` 内部解构 `kit`**，模块顶层不要调用 kit（stages.js 与场景模块是循环 import，顶层调用会拿到未初始化的绑定）。
- 不要 import 其它任何模块；不要改 `stages.js` / `objects.js` / `i18n.js` / `app.js` / 其它场景文件。

## 2. kit 助手（坐标单位：米）

所有 `x, z` 是**平面位置**（注意参数顺序是先 x 后 z），`y` 一律是**底面高度**（`o.y`）。

| 助手 | 说明 |
| --- | --- |
| `box(x, z, w, h, d, color, o)` | 长方体：宽 w 沿 x、高 h 沿 y、深 d 沿 z |
| `cyl(x, z, r, h, color, o)` | 圆柱（32 段） |
| `cone(x, z, r, h, color, o)` | 圆锥 |
| `sph(x, z, r, color, o)` | 球 |
| `prism(x, z, w, h, d, color, o)` | 三角柱（屋脊 / 山墙） |
| `slope(x, z, w, h, d, color, o)` | 楔形（坡屋面台阶） |
| `col(x, z, s, o)` | 希腊多立克柱，原高 10.3m，`s` 是缩放系数 |
| `item(type, x, z, ry, color?)` | 素材库物件：`table / lowTable / chair / sofa / bed / desk / bookshelf / bench / fridge / kitchenCounter / tv / door / window / pole / pillar / wall / lowWall / stairs / board` 等（见 `objects.js` 的 `parts()`） |
| `wallRun(axis, fixed, from, to, { h, t, color, y, openings })` | 墙：`axis:'x'` 沿 x 方向；`openings:[{start,end,y0,y1}]` 是门洞 / 窗洞 |
| `rng(seed)` | 固定种子随机（同一 seed 结果一致，保证画面稳定） |
| `tree(x, z, s, conifer?)` / `pole(x, z, h)` / `fence(x, z, len, ry, h)` / `house(x, z, w, h, d, i, ry, y)` | 常见户外零件 |
| `C` | 调色板：`C.floor / wall / wood / woodDark / stone / grass / road / roof / marble / sand ...` |
| `uid('s')` | 需要唯一 id 时用（一般不用管，助手已处理） |

`o` 可选字段：
- `y`：底面高度（墙、台面、檐口都靠它叠）
- `rx / ry / rz`：**弧度**（场景文件统一用弧度，内部会换算成角度）
- `occlude: true|false`：是否算「遮挡物」，会被「去掉墙壁遮挡」开关隐藏。
  大而薄的吊顶 / 屋面（>2m 高、两边都 >2m、长宽比 < 8）会自动识别，**其它需要跟着隐藏的构件请显式写 `occlude: true`**；楼板之类不想被隐藏的写 `occlude: false`。

## 3. 视觉风格（很重要）

这个工具是**漫画分镜**用的，默认「线稿（柔和）」外观下**白色面 + 深灰色边线**才是画面主角：

- **靠边线辨认形体**：多用薄片线脚、压边、嵌条、分缝（3–8cm 厚的 `box`），少用大片无细节的平面；一个大平面上加 2–3 道线脚就会立刻「有建模感」。
- 曲线构件可以放心用（圆柱 32 段、球 32×20）。
- 颜色克制、低饱和：墙 `#ece7dc / #e8e2d4 / #f3efe5`，木 `#8a6440 / #6b4a2f / #573e28`，瓦 `#4b525a / #5f676e`，石 `#9aa0a0 / #8b9296`，金属 `#c9cfd9`，玻璃 `#cfe4f2`，黄铜 `#c9a45c`，大理石 `#efeade`。
- 同一场景里颜色数量控制在 10~14 种以内，重复使用。
- 对称构件用循环生成，别手写 20 遍。
- **多边形预算：每个场景 ≤ 260 个 spec**（每个 spec = 1 次 draw call，现有最大场景 225 个）。宁可少而准，不要堆垃圾构件。

## 4. 相机机位（view）

- 室内：`pos` 高度 1.5~2.0m（人眼），`target` 对準室内主体，`lens` 24~28mm；房间尺度 6~12m 时距离 6~10m。
- 室外：`pos` 高度 3~8m（略高于人眼，能看到屋顶），距离按建筑尺度（20~45m），`lens` 26~35mm。
- 画面要留出「人物站位」：室内至少留一块 3m×3m 的空地，别被家具塞满。

## 5. 自检

1. `node --check src/scenes/<你的文件>.js`
2. 目测核对：所有构件都在地面以上（`y >= 0`），没有穿模的大面积重叠。
3. 不要跑浏览器 / Playwright —— 视觉验证由 Lead 统一做。
4. 完成后在总结里写：文件路径、场景 id、spec 数量、主要构件清单。

## 6. 参考资料（Lead 整理，本机网络不可用，凭已知资料整理）

### 旧岩崎邸庭園（東京都文京区湯島 / Kyū-Iwasaki-tei）
- 1896 年（明治 29）竣工，三菱財閥第 3 代当主 **岩崎久弥** 的本邸，设计 **约西亚·康德（Josiah Conder）**（鹿鸣馆、尼古拉堂的设计者）。用地约 1.5 万 m²。
- 三栋建筑：**洋館**（木造 2 层 + 地下室，英国雅各布样式 Jacobean）、**和館**（书院校舍风 + 数寄屋风）、**撞球室**（台球房，与洋馆以地下通道相连）。三栋都是重要文化财。
- **洋馆外观**：奶油色下见板张（横向木板墙）/ 灰泥墙；急坡切妻屋顶（多处破风）、山墙；砖砌烟囱；1 层朝庭园一侧有**外廊（ベランダ）**：细木柱 + 木栏杆；入口门廊有柱子和三角形山花（pediment）；上下推拉窗（白框、成对布置）；屋顶有老虎窗（dormer）。
- **洋馆内部（1 层）**：玄関ホール（中央大阶梯、木制扶手 + 格子状手摺子、两层通高的格天井）；大広間（暖炉 + 大理石/瓷砖的壁炉台、**金唐革纸**壁纸、格天井、枝形吊灯、寄木细工地板）；食堂（长餐桌 + 椅子、暖炉、餐具柜、吊灯）；走廊 + 厚重的木门；窗为上下推拉窗。
- **和馆**：书院校舍风大广间（榻榻米）、床の間 + 違い棚 + 欄間、障子 / 玻璃障子、面向池庭的**广缘（走廊）**、深檐、瓦屋顶。
- **庭园**：洋风草坪 + 日本庭园（池、雪见灯笼、飞石、松树、樱树）。

### 江西古建筑民居（赣派民居，现有场景要优化）
- 特征：**马头墙**（阶梯状跌级山墙 + 瓦压顶 + 叠涩线脚）、青砖墙 + 白灰粉墙（墙裙为青砖）、**四水归堂**天井、木构架（穿斗式）、檐下木雕（牛腿 / 雀替 / 挂落）、**格扇门窗**（木格心 + 裙板）、砖雕门罩、青石板巷、石缸 / 瓷瓶 / 八仙桌 / 太师椅 / 条案、宫灯、椽条 + 檩条 + 瓦垄屋面。
- 现有场景 id：`jiangxiExterior`（巷子 + 民居外观）、`jiangxiInterior`（三开间厅堂 + 天井）。
